# Binary redistribution notices

These verbatim files are inputs to `packaging/finalize`:

- `GCC-GPL-3.0.txt` is the GNU GPL version 3 text distributed by the
  [Free Software Foundation](https://www.gnu.org/licenses/gpl-3.0.txt).
- `GCC-RUNTIME-LIBRARY-EXCEPTION.txt` is `COPYING.RUNTIME` from the GNU
  Compiler Collection 14 distribution.
- `OpenBLAS.txt` is the license distributed by OpenBLAS. It is included only
  in Linux archives, which statically link OpenBLAS.

The AENET license is copied from the repository root. The L-BFGS-B notice is
extracted from the bundled `lib/Lbfgsb.3.0.tar.gz` source archive so the notice
and source cannot silently diverge.
